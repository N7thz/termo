# Temas de terceiros

`splash-themes.json` traz os esquemas de cores publicados no [TerminalSplash](https://terminalsplash.com/)
(galeria de temas do Windows Terminal, por LukeHero). Cada tema guarda o autor e o link do repositório de
origem, que aparecem no seletor de temas do app (⚙ → Tema → "fonte").

- 214 dos esquemas vêm de [mbadolato/iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes),
  sob licença MIT (Copyright (c) 2011 Mark Badolato).
- Os demais vêm dos repositórios dos próprios autores, indicados no campo `source` de cada tema.

Só as cores são usadas: perfis, fontes e imagens de fundo dos temas originais não entram no app.
Para atualizar: veja `scripts/import-terminalsplash.mjs`.
